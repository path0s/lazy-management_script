### 📖 Overview

**LZY** creates a main folder named with the current date (`yyyy-mm-dd`).  
Inside it, the script generates one subfolder per file format found in the target directory and moves each file into its matching format folder.  
It also produces a **`report.txt`** summarizing the run and listing the newly created folders.

We often tend to be lazy and neglect organizing our folders - like the classic **Downloads** folder.  
This script helps reorganize them by sorting their contents in a clearer, tidier way.

### 🚀 Usage

The script needs the path of the directory as argument.

**On Linux:**
```sh
./lzy.sh /home/linux/Desktop/Folder
```

**On Windows:**  
Download [Git or Git Portable](https://git-scm.com/download/win) from the official website, then:
```sh
./lzy.sh C:\\Users\\path0s\\Desktop\\Folder
```
